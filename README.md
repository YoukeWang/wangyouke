# 海外硕士录取标准分析模型

这是一个面向留学申请场景的轻量级 `Streamlit` 交互式数据分析工具。项目参考“海外硕士录取标准可视化工具”的思路，将录取要求拆成 **硬门槛、专业匹配、软实力** 三个维度，帮助申请者快速进行初步选校分层。

## 项目定位

- **赛道**：交互式数据分析工具（Track 4）
- **主题**：留学申请 / 海外硕士录取标准分析
- **目标用户**：准备申请海外商科、数据类硕士的本科生
- **核心价值**：把项目门槛、申请人背景和匹配建议放到同一个可交互页面中，辅助完成保底、匹配、冲刺分层

## 功能说明

- 展示海外硕士项目的 GPA、雅思、托福、GRE、专业背景、学费等要求
- 支持输入申请人画像：
  - 本科背景
  - GPA
  - 本科专业匹配度
  - 数学/统计基础
  - 编程基础
  - 雅思、托福、GRE
  - 实习、科研、项目经历
  - 预算和目标国家/地区
- 自动计算 `录取匹配指数`
- 输出 `保底 / 匹配 / 冲刺 / 暂不达标` 四类结果
- 展示项目门槛散点图、匹配结果分布、费用对比和单项目得分拆解
- 支持下载样例数据

## 模型逻辑

本项目不是官方录取预测器，而是用于课堂展示的规则加权模型：

```text
录取匹配指数 = 50%×硬门槛 + 30%×专业匹配 + 20%×软实力 + 预算修正 - 竞争度惩罚
```

### 1. 硬门槛

主要包括：

- GPA 与本科院校背景
- 雅思或托福成绩
- GRE 是否必需以及是否达标

### 2. 专业匹配

主要包括：

- 本科专业是否相关
- 数学/统计基础
- 编程基础

### 3. 软实力

主要包括：

- 相关实习时长
- 科研/论文经历
- 数据分析或商业分析项目经历

## 数据说明

- 数据文件：`data/masters_admission_sample.csv`
- 数据规模：22 个样例硕士项目
- 覆盖地区：英国、美国、新加坡、中国香港、澳大利亚、加拿大、荷兰
- 专业方向：`Business Analytics`、`Data Science`、`Data Analytics`、`Information Systems`、`Statistics`、`Applied Computing`
- 注意：数据为课堂演示样例，参考常见申请门槛区间整理，不代表院校最新官方录取标准，真实申请前必须以学校官网为准

## 项目文件

- `reports/仍需人工确认项清单.md`：仍需人工确认项清单

## 运行方式

1. 安装依赖：

```bash
pip install -e .
```

2. 启动应用：

```bash
streamlit run main.py
```

3. 打开本地页面：

```text
http://localhost:8501
```
